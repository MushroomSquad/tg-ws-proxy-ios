# Vibe-coded / Собран с LLM

## English

Large parts of this iOS port were written with **LLM coding assistants** (vibe-coding). Treat releases as community / best-effort. Prefer reading the Swift sources. Bug reports with exported logs help more than “it doesn’t work”.
